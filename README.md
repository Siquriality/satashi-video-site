# Satashi DDoS Visual

Самостоятельная браузерная страница с анимированной визуализацией сетевой нагрузки в стиле Satashi. Это графический макет: страница не посылает сетевые запросы для нагрузки на сервер и не показывает телеметрию реальной сети.

## Запуск

Откройте `index.html` в современном браузере. Файл содержит разметку, стили и сценарии страницы; установка зависимостей не требуется.

## Назначение

Макет можно использовать для показа идеи интерфейса и обсуждения визуального оформления. Для реальных метрик потребуется отдельно подключить источник данных. Лицензия на повторное использование не указана.
